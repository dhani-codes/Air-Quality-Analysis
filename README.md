# Air Quality Analysis

## Project Overview
This project analyzes air quality using Python, statistics, and machine learning.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Gradio

## Features
- Data cleaning and exploratory data analysis
- Statistical analysis, including t-tests, z-tests, correlation, and covariance
- AQI prediction using machine learning
- Interactive Gradio dashboard

## Dataset
The dataset is simulated for educational purposes and does not represent official live air-quality measurements.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `Air_Quality_Analysis.csv`.
3. Run the notebook cells in order.
4. Run the final cell to launch the Gradio interface.
